ULTRAPROMPT CURSOR — REFONTE DESIGN GLOBALE ANS ORION
COHÉRENCE VISUELLE, HARMONIE, UI/UX PREMIUM, TOUS MODULES, DESIGN SYSTEM COMPLET

RÔLE
Tu es un expert senior UI/UX Designer, Product Designer SaaS/ERP, Directeur artistique digital, Design System Architect, Typographe, spécialiste colorimétrie, iconographie, mise en page, ergonomie, React / Next.js / TypeScript / Tailwind, CRM, ERP, POS, GPAO, Backoffice, Finance, Stock, Production, Logistique, RH et messagerie métier.

MISSION GLOBALE
Faire une refonte / mise au point complète du design de ANS ORION afin d’obtenir une interface premium, harmonieuse, moderne, professionnelle, cohérente et digne d’un SaaS / CRM / ERP d’imprimerie et d’agence design.

Tous les modules doivent être revus côté design avec cohérence visuelle et harmonie globale.

IMPORTANT
Ne pas casser les fonctionnalités existantes.
Ne pas modifier les règles métier validées.
Ne pas casser les routes.
Ne pas casser les API.
Ne pas casser Prisma.
Ne pas supprimer les éléments utiles.
Ne pas refaire le projet depuis zéro.
Ne pas supprimer bêtement des modules, champs, boutons, onglets ou actions.
Toute amélioration design doit préserver ou mieux organiser les fonctionnalités existantes.

OBJECTIF FINAL
ANS ORION doit devenir une application visuellement très professionnelle :
- plus belle ;
- plus cohérente ;
- plus harmonieuse ;
- plus facile à lire ;
- plus facile à manipuler ;
- plus premium ;
- plus moderne ;
- plus stable visuellement ;
- plus proche des meilleurs standards SaaS / CRM / ERP / design agency entre 2020 et 2026.

Le design doit être digne d’une œuvre réalisée par un vrai professionnel UI/UX, colorimétrie, typographie, iconographie et mise en page.

ÉTAPE 3 — RÈGLE GLOBALE DES ARRONDIS
==================================================

Règle obligatoire :
Tous les rectangles arrondis doivent utiliser un rayon uniforme de 10 px.

Créer un token global :
--radius-ui: 10px;

Dans Tailwind :
- rounded-[10px]
ou
- rounded-ui si configuré.

Appliquer 10 px à :
- cartes ;
- panneaux ;
- boutons ;
- inputs ;
- selects ;
- textareas ;
- modales ;
- drawers ;
- popovers ;
- chips ;
- badges rectangulaires ;
- tabs ;
- toolbars ;
- lignes sélectionnées ;
- items de listes ;
- cartes KPI ;
- cartes commandes ;
- blocs formulaire ;
- blocs dashboard ;
- panneaux ANS Talk ;
- sections Backoffice ;
- composants POS ;
- composants Devis ;
- composants Commandes.

Éviter :
- rounded-sm ;
- rounded-md ;
- rounded-lg ;

- rounded-2xl ;

- pas de glassmorphism excessif ;

Texture possible sur fond global uniquement :

radial-gradient(circle at bottom right, rgba(255,178,26,0.06), transparent 30%);

ÉTAPE 6 — ANTI “CARD DANS CARD DANS CARD”
==================================================

Règle stricte :
Maximum 1 niveau de carte dans une carte.

Interdit :
Page → Card → Card → Card.

Toléré :
Page → SectionCard → contenu simple.

Préférer :
- sections ouvertes ;
- dividers subtils ;
- grids ;
- lignes ;
- tabs ;
- panels simples ;
- badges ;
- états sélectionnés.

À corriger en priorité :
- Backoffice ;
- Commandes ;
- ANS Talk ;
- POS ;
- Devis ;
- Panier ;
- CRM.

Ne pas utiliser une carte uniquement pour créer de l’espace.
Utiliser plutôt : gap, grid, padding, divider, section header.

ÉTAPE 7 — MISE EN PAGE, MARGES, GOUTTIÈRES, BLANCS
==================================================

Mission :
Unifier tous les espaces avant/après, marges, paddings, gaps, gouttières et blancs.

Règle fondamentale :
Même niveau = même espacement.

Échelle recommandée :
- 4 px / gap-1 : micro éléments ;
- 8 px / gap-2 : icône + texte, badges ;
- 12 px / gap-3 : groupes compacts ;
- 16 px / gap-4 : cartes, formulaires, sections internes ;
- 24 px / gap-6 : grandes sections ;
- 32 px / gap-8 : séparation majeure uniquement.

Page :
- px-4 md:px-6 xl:px-8 ;
- py-4 ou py-6 ;
- space-y-6 entre grandes sections.

Cartes :
- compactes : p-3 ;
- standard : p-4 ;
- importantes : p-5 ;
- ne pas mélanger p-2, p-6, p-8 dans un même groupe.

Grids :
- KPI : gap-4 ;
- cartes : gap-4 ;
- compact : gap-3 ;
- formulaires : gap-x-4 gap-y-4 ;
- layout deux colonnes : gap-4 ou gap-5.

Tables :
- cellule : px-3 ou px-4 ;
- cellule : py-3 ;
- toolbar vers tableau : mt-4.

Tabs :
- tabs vers contenu : mt-4 ;
- gap entre tabs : gap-1 ou gap-2 ;
- padding tab : px-3 py-2.

À corriger :
- grands vides non justifiés ;
- éléments collés ;
- marges aléatoires ;
- gouttières irrégulières ;
- axes d’alignement incohérents.

ÉTAPE 8 — TYPOGRAPHIE PROFESSIONNELLE
==================================================

Objectif :
Typographie digne d’un CRM d’imprimerie / agence design.

Police UI principale :
- Manrope, Geist Sans ou Inter.

Police mono :
- uniquement pour codes, références, IDs, numéros commande, logs.

Échelle :
- titre page : text-2xl font-semibold tracking-tight ;
- titre section : text-lg font-semibold ;
- titre carte : text-base font-semibold ;
- corps : text-sm ou text-base ;
- meta : text-xs ou text-sm muted ;
- bouton : text-sm font-semibold ;
- badge : text-xs font-medium ;
- KPI : text-xl ou text-2xl font-semibold tabular-nums ;
- montants : tabular-nums.

À éviter :
- trop de tailles différentes ;
- text-xs pour contenu principal ;
- text-3xl abusif ;
- font-bold partout ;
- uppercase excessif ;
- titres trop grands.

Règles françaises :
- espace avant : ; ? ! ;
- espace entre nombre et unité : 120 cm, 300 mm, 50 % ;
- montants : 86 216 Ar ;
- accents sur majuscules : À, É, État ;
- points de suspension : … ;
- apostrophe typographique si possible : aujourd’hui.
