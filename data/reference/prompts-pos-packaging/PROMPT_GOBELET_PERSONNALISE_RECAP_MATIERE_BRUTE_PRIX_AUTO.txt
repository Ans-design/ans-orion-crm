PROMPT — GOBELET PERSONNALISÉ + RÉCAPITULATIF MATIÈRE BRUTE GLOBAL POS — ANS ORION

Contexte :
On travaille sur le POS ANS ORION, notamment l’article “Gobelet personnalisé”.
La correction doit aussi améliorer le fonctionnement global du “récapitulatif matière brute” sur tous les articles POS, car ce récapitulatif définit la surface réelle de matière d’impression, la surface brute, les marges, les chutes, le stock, le prix et la production.

Objectif :
Le module “Gobelet personnalisé” doit calculer automatiquement la surface d’impression, le prix, les marges, le stock et le récapitulatif matière brute.
Il ne faut pas se limiter à un simple “prix à définir”.
Les calculs doivent être pilotés par des règles métier, des formules, des prix admin/back-office et des snapshots dans les devis/commandes/factures.

IMPORTANT :
Ne pas corriger seulement le frontend.
Toute correction doit être synchronisée avec :
- POS
- Base de données
- Admin / Back-office
- Prix
- Formules
- Règles métier
- Stock
- Panier
- Devis
- Commande
- Facture
- Fiche production
- Cockpit
- Seeds
- Tests

============================================================
1. RÈGLE GLOBALE — RÉCAPITULATIF MATIÈRE BRUTE POS
============================================================

Sur tous les articles POS, le récapitulatif matière brute doit fonctionner correctement.

Le récapitulatif matière brute doit afficher les données qui définissent la surface de matière utilisée pour l’impression, le façonnage, le stock et le prix.

Il doit afficher automatiquement selon l’article :
- Dimensions client
- Surface réelle
- Surface d’impression
- Surface brute
- Marges de chute
- Fond perdu / bleed si applicable
- Matière
- Quantité
- Surface totale
- Stock consommé
- Base de calcul prix
- Prix automatique
- Finition
- Total

Le récapitulatif matière brute ne doit jamais être vide ou incohérent si un article utilise :
- dimensions personnalisées
- surface d’impression
- format personnalisé
- impression partielle
- impression totale
- matière imprimable
- support avec prix au m²
- support avec prix par format/feuille

3. IMPRESSION PARTIELLE — LONGUEUR × LARGEUR OBLIGATOIRE
============================================================

Si l’utilisateur choisit “Impression partielle”, afficher obligatoirement :
- Longueur zone impression en mm
- Largeur / hauteur zone impression en mm

Formule :
surface_impression_partielle_m2 = longueur_zone_mm × largeur_zone_mm / 1 000 000

Si quantité > 1 :
surface_impression_partielle_totale_m2 = surface_impression_partielle_m2 × quantité

Cette surface doit être calculée automatiquement et affichée dans le récapitulatif matière brute.

Règle :
Si “Impression partielle” est sélectionnée, le prix ne doit pas être manuel.
Il doit être calculé automatiquement selon :
- surface d’impression
- quantité
- type de gobelet
- type d’impression
- couleur d’impression
- finition
- minimum de production
- prix admin/back-office

============================================================
4. IMPRESSION TOTALE / FULL WRAP
============================================================

Si l’utilisateur choisit “Impression totale / full wrap”, le système doit calculer la surface d’impression à partir du gabarit du gobelet.

Deux possibilités :

A. Si le gabarit du gobelet existe dans la base :
Utiliser :
- surface_gabarit_impression_m2
- largeur_gabarit_mm
- hauteur_gabarit_mm
- coefficient_courbure si nécessaire

B. Si le gabarit n’existe pas :
Afficher une alerte :
“Gabarit d’impression totale non défini pour cette contenance. Veuillez configurer le gabarit dans l’admin.”

Ne pas laisser le prix vide.
Si le gabarit est absent :
- empêcher la validation automatique
OU
- basculer en statut “prix à valider par admin”
Mais ne pas afficher “prix à définir” comme comportement normal.

Formule possible si gabarit disponible :
surface_impression_totale_m2 = surface_gabarit_impression_m2
surface_impression_totale_commande_m2 = surface_gabarit_impression_m2 × quantité

============================================================
5. MARGE DE CHUTE MATIÈRE / IMPRESSION
============================================================

Pour les zones d’impression personnalisées, appliquer la marge de chute matière si l’impression utilise un film, adhésif, transfert, DTF, support imprimé ou matière consommable.

Règle standard :
- +50 mm à gauche
- +50 mm à droite
- +50 mm en haut
- +50 mm en bas

Donc :
longueur_brute_zone_mm = longueur_zone_mm + 100
largeur_brute_zone_mm = largeur_zone_mm + 100

surface_brute_impression_m2 = longueur_brute_zone_mm × largeur_brute_zone_mm / 1 000 000
surface_brute_totale_m2 = surface_brute_impression_m2 × quantité

Important :
La marge +50 mm est une marge matière / chute / calage / déchet.
Elle ne remplace pas :
- marge de sécurité design
- fond perdu
- tolérance de pose
- marge machine

Si certaines techniques de gobelet ne consomment pas une matière à plat, l’admin doit pouvoir désactiver ou adapter cette marge par technique d’impression.

7. PRIX AUTOMATIQUE — PAS JUSTE “PRIX À DÉFINIR”
============================================================

Le prix du Gobelet personnalisé doit être calculé automatiquement.

Créer ou corriger les formules dans l’admin/back-office.

Base de prix possible :
prix_total =
prix_gobelet_base × quantité
+ prix_impression
+ prix_finition
+ prix_calage
+ prix_façonnage
+ prix_minimum_production
+ marge_commerciale

Pour impression partielle :
prix_impression =
surface_brute_totale_m2 × prix_m2_technique_impression

Pour impression totale :
prix_impression =
surface_gabarit_impression_m2 × quantité × prix_m2_technique_impression

Ajouter les coefficients :
- coefficient selon type de gobelet
- coefficient selon contenance
- coefficient selon technique d’impression
- coefficient selon quantité
- minimum de production
- supplément urgence si applicable
- supplément finition si applicable

Le prix forcé manuel doit rester uniquement une option admin exceptionnelle, non obligatoire.

14. RÉSULTAT ATTENDU
============================================================

Après correction :
- Le Gobelet personnalisé calcule automatiquement la surface d’impression.
- En impression partielle, longueur × largeur sont obligatoires et calculés dans le récapitulatif.
- En impression totale, le système utilise un gabarit admin.
- Le prix est automatique, basé sur les formules et le back-office.
- Le prix forcé n’est plus une obligation normale.
- Le récapitulatif matière brute fonctionne sur tous les articles POS.
- Le stock, les devis, les factures, la production, l’admin et le cockpit sont synchronisés.
