Contexte :
On travaille sur le POS ANS ORION, dans le module / catégorie “Calendrier”.
Ce prompt reformule et regroupe toutes les consignes déjà données sur les calendriers, afin de corriger tous les articles calendrier de manière cohérente, propre et synchronisée.

2. CORRIGER LES CONFUSIONS ENTRE ARTICLES
============================================================

Il y a une confusion possible entre :
- Calendrier plateau (mural/bureau)
- Calendrier mural
- Sous-main
- Chevalet de bureau / calendrier bureau à feuillets

Action obligatoire :
Auditer et corriger les configurations mal placées.

Règle :
- Un article “Calendrier mural” doit contenir les options adaptées à un calendrier mural.
- Un article “Calendrier plateau (mural/bureau)” doit contenir uniquement les options adaptées au plateau/calendrier rigide.
- Un article “Sous-main” doit contenir uniquement les options sous-main.
- Un article “Chevalet de bureau” doit gérer les feuillets, pas les formes 3D.
- Les formes 3D comme cube, pyramide, cylindre, prisme ne doivent pas être dans Calendrier ; elles appartiennent à “Chevalet de table simple” si cet article existe ailleurs dans la POS.

Ne pas dupliquer les options.
Ne pas laisser les anciennes options dans le mauvais article.

============================================================
9. FORMAT PERSONNALISÉ — TOUS LES CALENDRIERS
============================================================

Si un calendrier utilise un format personnalisé :

Supprimer le bloc inutile :
- “Dimensions personnalisées”
- champ texte “Format”
- zone texte “Autres précisions : forme, contraintes de production...”

Garder uniquement :
- Longueur L en mm
- Largeur l en mm

Calcul :
surface_reelle_m2 = L × l / 1 000 000

Marge de chute matière :
- +50 mm à gauche
- +50 mm à droite
- +50 mm en haut
- +50 mm en bas

Donc :
largeur_brute_finale = l + 100 mm
longueur_brute_finale = L + 100 mm

surface_brute_m2 = longueur_brute_finale × largeur_brute_finale / 1 000 000
surface_brute_totale_m2 = surface_brute_m2 × quantité

Important :
Cette marge +50 mm est une marge matière/chute/calage/déchet.
Elle ne remplace pas :
- le fond perdu ;
- la marge de sécurité design ;
- la tolérance machine ;
- la marge de coupe.

============================================================
11. CALCUL DE PRIX AUTOMATIQUE — TOUS LES CALENDRIERS
============================================================

Le prix doit être automatique.
Ne pas afficher “prix à définir” comme comportement normal.

Formule générale :
prix_total =
prix_matiere
+ prix_impression
+ prix_finition
+ prix_decoupe
+ prix_perforation
+ prix_reliure_spirale
+ prix_support
+ prix_accessoire
+ prix_calage
+ minimum_production
+ marge_commerciale

Prix matière :
prix_matiere = surface_brute_totale_m2 × prix_m2_matiere

Prix impression :
- recto : surface_reelle_totale × prix_m2_impression_recto
- recto-verso : surface_reelle_totale × prix_m2_impression_recto_verso

Pour calendriers à feuillets :
prix_feuillets =
surface_feuillet × nombre_feuillets × quantité × prix_m2_matiere_feuillet
+ impression_feuillets
+ façonnage_feuillets

Le prix forcé manuel doit rester uniquement une option admin exceptionnelle, non obligatoire.

14. STOCK
============================================================

Le stock doit être calculé avec la surface brute.

Pour format standard :
stock_consomme = surface_format × quantité

Pour format personnalisé :
stock_consomme = surface_brute × quantité

Pour calendrier à feuillets :
stock_support = surface_support × quantité
stock_feuillets = surface_feuillet × nombre_feuillets × quantité
stock_total = stock_support + stock_feuillets

Alertes avant ajout panier :
- matière indisponible
- grammage interdit
- Offset sélectionné dans Calendrier marque-page
- stock insuffisant
- prix matière manquant
- prix impression manquant
- format incompatible
- nombre de feuillets manquant si article à feuillets
