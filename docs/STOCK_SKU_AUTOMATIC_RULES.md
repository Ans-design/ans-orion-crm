# Stock — règles SKU automatique

## Service

`lib/server/modules/stock/stock-sku.service.ts`  
API : `POST /api/stock/items/generate-sku`

## Format SKU

Pattern : **5 lettres majuscules** + suffixe caractéristiques normalisées.

Exemples de segments :
- Famille / type papier (ex. `OFFSET`, `BACHE`)
- Grammage ou épaisseur (`300G`, `5MM`)
- Format (`A4`, `320X450`)
- Couleur abrégée (`BLC`, `NR`)

Le SKU généré est **unique** : collision → incrément numérique ou suffixe.

## Déclenchement

1. **Bouton « Générer SKU »** dans la modale Nouveau SKU (`app/(app)/stock/page.tsx`)
2. **Création article** avec `autoSku: true` dans le body → `stock.service.ts` appelle `generateStockSku()` avant insert

Champ `skuAutoGenerated: true` trace les SKU non saisis manuellement.

## Entrées du générateur

| Champ | Source |
|-------|--------|
| `label` | Libellé article |
| `paperType` / `materialKey` | Type matière |
| `grammage`, `thickness` | Caractéristiques |
| `formatLabel`, `width`, `height` | Format |
| `color` | Couleur |
| `stockCategory` | Préfixe logique selon catégorie |

## Bonnes pratiques

- SKU manuel toujours possible (écrase l'auto)
- Ne pas réutiliser un SKU archivé sans vérification
- Le SKU reste l'identifiant opérationnel stock ; `materialKey` reste la clé Backoffice matières
