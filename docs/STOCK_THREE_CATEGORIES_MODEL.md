# Stock — modèle 3 catégories

## Vue d'ensemble

Chaque `StockItem` possède une **catégorie stock** obligatoire (`stockCategory`) :

| ID | Libellé | Usage |
|----|---------|-------|
| `vente_directe` | Vente directe | Articles revendus tels quels (fournitures, accessoires boutique) |
| `hybride` | Hybride | Vente directe **et** consommation production (mugs vierges, supports mixtes) |
| `matiere_interne` | Matière interne | Papier, vinyle, encre, consommables — alimentent Matières DB / POS / production |

Constantes partagées : `lib/data/stock-categories.ts`  
Badge UI : `components/stock/StockCategoryBadge.tsx`  
Filtres page stock : `app/(app)/stock/page.tsx`

## Champs Prisma (`StockItem`)

- `stockCategory` — catégorie principale
- `vendableDirectement` — vente directe autorisée
- `salePrice`, `marginPct` — prix vente et marge (obligatoires pour vente directe / hybride vendable)
- `unitDisplay`, `unitStandard`, `conversionFactor` — unités commerciales et conversion vers unité standard (m², feuille, etc.)
- `baseMaterialId` — liaison vers `BaseMaterial` (matière interne / hybride)
- `skuAutoGenerated`, `thickness`, `color`, `formatLabel` — caractéristiques SKU

## Règles métier

1. **Vente directe** — pas de liaison Matières DB obligatoire ; déduction stock à la vente directe.
2. **Hybride** — prix vente + liaison matière recommandée ; sync quantités/prix achat vers Backoffice.
3. **Matière interne** — liaison matière auto ou manuelle ; invisible POS catalogue direct ; impact formules/devis.

## API & services

- Création / liste : `lib/server/modules/stock/stock.service.ts`
- Validation Zod : `lib/server/modules/stock/stock.validation.ts`
- Filtres liste : `stockCategory`, `vendable`, `linkedMaterial` via `StockListQuery`

## Zéro suppression

Les onglets Stock existants (Achats, Fournisseurs, Mouvements, Ventes directes) sont conservés ; la catégorisation enrichit le module sans le remplacer.
